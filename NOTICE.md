# Attribution and local changes

This project is derived from **MacOS Style Dock 1.0** by **Zach Vaughn** (@zachvdev), published in the [Windhawk mods repository](https://github.com/ramensoftware/windhawk-mods/blob/main/mods/macos-style-dock.wh.cpp).

The upstream source credits m417z's Taskbar height and icon size, Taskbar Multirow and Taskbar auto-hide when maximized implementations. Their attribution and GPL-3.0 notices remain in the source.

The local modifications, published by haycel07 on 2026-11-11, add badge/overlay positioning and clipping handling, a non-interactive system-tray glass plate, and removal of an unnecessary additional frame-height allowance. Build and portable installation helpers are included.

The supplied DLL is a local build of the supplied source. It is not an upstream release and is not signed by the original author. No Windhawk engine or compiler binaries are redistributed here. Install Windhawk from its official source.
